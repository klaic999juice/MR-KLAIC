# Page Forge Studio

A lightweight editing website built as a static HTML/CSS/JavaScript app. It is designed to be easy to deploy on Vercel with zero build step.

## Features

- Live HTML editing
- Instant preview pane
- Theme toggle
- Accent color customization
- Copy or download generated HTML
- Local persistence using `localStorage`

## Deploy on Vercel

1. Push this repository to GitHub.
2. In Vercel, click "Add New Project" and import the repo.
3. Use the default settings.
4. Click "Deploy".

Vercel will serve the static site automatically from the root `index.html`.

## Local preview

Open `index.html` in a browser, or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` - app layout
- `styles.css` - styling
- `script.js` - editor logic

This app is intentionally simple so it remains fast, reliable, and easy to customize.

## Customize

Edit the default sample content in `script.js` under `defaultMarkup` to change the starter design.
