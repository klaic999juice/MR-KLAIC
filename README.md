# React + Vite project for the website editor

This project was converted from the static HTML version into a React app for easier development and deployment.

## Prerequisites

- Node.js 18+

## Install dependencies

```bash
npm install
```

## Run locally

```bash
npm run dev
```

Then open the URL shown in the terminal.

## Build for production

```bash
npm run build
```

## Deploy on Vercel

1. Push this repo to GitHub.
2. Import it into Vercel.
3. Use the default settings.
4. Deploy.

Vercel will automatically detect the React + Vite app.
